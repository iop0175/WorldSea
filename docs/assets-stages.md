# 샵 2~4단계 장면 에셋 목록 (객체 분해)

결정(대장님, 2026-10-13)
1. 2~4단계도 **1단계처럼 개별 객체로 쪼개서** 만든다. 장면 통짜 그림은 쓰지 않는다.
2. **교배실은 1단계 유리 돔을 재사용**한다 (직원 전용 문으로 대신하지 않음).
3. **4단계도 한 화면(360×462)만** 만든다. 드래그로 둘러보는 큰 장면은 만들지 않는다.

- 지금 `bg/hub_stage2~4.png`는 시안 크롭 임시본이다. 아래 객체와 빈 방 배경이 갖춰지면 1단계(`docs/assets-main.md`)와 같은 방식으로 교체한다.
- 만드는 법·공통 스타일 문구·3겹 수조 구조(`_back` → 물고기(코드) → `_front`)·글자 금지·pixelize.py 사용은 assets-main.md와 같다.
- 새로 그리는 파일은 `packages/client/src/assets/obj/s<단계>/<이름>.png`. 좌표는 **장면 영역 360×462 기준**(게임 y = 38 + 아래 y). 시안 크롭을 격자로 읽은 **대략값**이라, 그릴 때 칸에 맞춰 ±5px 조정한다.
- 크기는 `w×h @ (x,y)`.

## 0. 모든 단계 공통 규칙
1. **물고기가 아닌 생물은 그리지 않는다** (확정). 시안의 해파리 원기둥 → 물고기 원기둥, 거북 곡면 수조 → 물고기 수조, 펭귄 풀 → 물고기 터치 풀.
2. **쥐가오리는 어종 목록에 없다.** 시안의 쥐가오리 수조는 물고기로 채운다. 고래상어는 목록에 있다(전설). 대형 수조 그림(`_back`)에는 넣지 않고 진열한 개체를 코드가 그린다.
3. 관람객·점원은 그림에 넣지 않는다. 걷는 사람은 `chr/` 시트를 코드가 움직인다.
4. **1단계 객체 재사용(새로 안 그림)**: `obj/counter` `obj/door_double` `obj/mat` `obj/plant_a` `obj/plant_b` `obj/lamp_wall` `obj/painting_a` `obj/painting_b` **`obj/breeding_back/_front`(유리 돔, 58×136)** **`obj/tank_fry_back/_front`(치어 수조, 80×80)**. 새 객체가 아니므로 아래 장수에 포함하지 않는다.
5. **빈 방 배경** `bg/hub_stage<n>.png` 360×462, 세 단계 모두 한 화면. 수조·가구·사람·글자 없음. 뒷벽·바닥·난간 틀만.
6. **기능 지점은 모든 단계에 있어야 한다**: 카운터(NPC 판매), 시장 입구, 길드 입구, 교배실(유리 돔), 치어 육성, 진열 수조들.
7. **유리 돔·치어 수조 자리를 만들려고 빠지는 시안 객체**가 있다(단계별 아래 표). 돔은 58×136으로 커서 수조 1~2개와 자리가 겹친다.

## 5. 코드 쪽 후속 (에셋 도착 후)
- `layout.ts`에 `STAGE2_SPOTS` `STAGE3_SPOTS` `STAGE4_SPOTS`(위 표의 @좌표) 추가, `HubScene`이 단계별 spots로 객체를 놓고, 간판·라벨(`App.tsx`)도 같은 spots를 읽도록 일반화.
- 지금은 2~4단계에서 1단계 전용 오버레이(간판 글자·시장/길드 명판)를 숨겨 두었다.
- 교배 완료 말풍선(`fx/bubble_dna`)은 모든 단계에서 유리 돔 위에 뜬다.
- 샵 업그레이드 화면(`shop_upgrade`)의 "다음 단계 미리보기"는 완성된 장면 합성본을 쓴다.

## 6. 수량 요약
