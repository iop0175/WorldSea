# 메인 화면(샵 허브) UI 기준 (v2)

- **기준 이미지: `docs/reference/main-ui-reference.png`** (대장님 제공, 941×1672, 9:16, 탑다운 3/4 시점)
- 이전 쿼터뷰 시안은 `docs/reference/main-ui-reference-v1.jpg`로 보관만 한다 (기준 아님).
- 화면 배치, 패널 모양, 색감, 아이콘 스타일, 샵 장면 구성은 v2 이미지를 따른다.
- v2 이미지는 생성 도구로 만든 "픽셀 느낌" 고해상도 그림이라 점 크기가 일정하지 않다. **에셋으로 직접 쓰지 않고**, 아래 해상도에서 점 크기가 일정한 진짜 픽셀아트로 새로 그린다.
- 이미지에서 글자가 빠진 부분(헌터 띠 윗줄, 카드 글자, 탭 이름 등)은 이 문서의 3장 규칙대로 UI 레이어에서 채운다.

## 3. UI 요소

### ① 상단바 (한 줄)
왼쪽부터: **프로필**(헌터 얼굴 + 닉네임 + `LV.12` + 경험치 바) · **프리미엄**(보라 보석 + 숫자 + `+`) · **골드**(금화 + 숫자 + `+`) · **스태미너**(번개 + `32/60`, 아래 `+1 04:12`) · **시간 티켓**(모래시계 + 숫자) · **메뉴**(햄버거 + 빨간 배지, 우편 포함 새 소식 수).
- 터치 영역은 보이는 크기와 별개로 최소 44pt를 확보한다(투명 여백).

### ② 샵 장면 위 UI
- **간판**: 뒷벽 가운데, 물결·산호 장식이 있는 나무 명판. 이미지에서 비어 있는 명판 위에 "월드씨 브리딩샵"을 UI 글자로 얹는다.
- **샵 단계 바**(되살림): 간판 아래. "1단계 동네 샵" + 금색 진행바 + `62%`.
- **왼쪽 패널**: 출석(달력, 배지) / 복원(분재). **오른쪽 패널**: 가방 / 친구. 아이콘 아래 이름 글자(되살림).
- **장면 라벨**: 수조·카운터·문 위에 어두운 반투명 명판 + 흰 글자 (UI 레이어). 기본은 표시, 설정에서 끌 수 있게.
- **머리 위 말풍선**: 손님 대기, 교배 완료(DNA), 치어 성장 완료 등.

### ③ 헌터 띠
- **윗줄(되살림)**: `헌터`(금색) + `1명 수색중 · 1명 완료` ……… `모두 수령`(금색 버튼).
- **카드 4개** (가로 4등분):
  - 수색 중: **지역 그림이 카드 배경**(이미지처럼 바닷속 장면) + 지역명 + `37/100  02:41` + 진행바
  - 완료: 금색 세계지도 배경 + 지역명 + `완료 · 수령`
  - 잠김: 자물쇠 + `LV.10 해금` / `구독 해금`

### ④ 하단 탭바
- 5칸 균등: 샵(차양 가게) / 사육(물고기 수조) / 원정(지도) / 도감(왕관 책) / 상점(파란 바구니).
- 아이콘 아래 **탭 이름**(되살림). 활성 탭은 금색 바탕. **메인 화면에서는 샵이 활성** (이미지는 사육이 활성으로 잘못 그려짐).
- 알림 배지는 아이콘 오른쪽 위.

## 4. 샵 장면 (탑다운 3/4 시점)

### 시점 규칙
- 위에서 내려다보되 물건의 윗면과 앞면이 함께 보인다 (포켓몬·스타듀밸리식).
- 수조는 윗면(물 표면) + 앞 유리가 보이고, **물고기는 옆모습**으로 그린다 (모프가 보이게).
- 그리기 순서는 y 좌표 기준 정렬(아래에 있는 것이 앞).
- 플레이어 캐릭터, 점원, 손님이 바닥을 걸어 다닌다 (4방향 걷기).

### 샵 단계별 모습 (대장님 제공 이미지)
샵은 단계마다 장면 그림 자체가 바뀐다. 상단바·헌터 띠·탭바는 모든 단계에서 같다.

| 단계 | 기준 이미지 | 모습 |
|---|---|---|
| 1단계 동네 브리딩샵 | `main-ui-reference.png` | 방 하나. 벽 선반 수조, 메인 수조, 교배 장치, 치어 수조, 카운터, 시장·길드 문 |
| 2단계 (작은 수족관) | `hub-stage2-reference.png` | 방 하나, 더 넓음. 뒷벽 전체 대형 수조, 해파리 원기둥 수조, 메인 전시 수조, 곡면 수조, 터치 풀, 관람객, 벤치, 안내 키오스크 |
| 3단계 | (이미지 없음) | 2단계와 4단계 사이. 예: 2층 일부 개방, 터널 수조 시작 |
| 4단계 공공 수족관 | `hub-stage4-reference.png` | 여러 층. 초대형 수조(고래상어), 원기둥 수조, 터널 수조, 펭귄 풀, 기념품 가게, 에스컬레이터, 다수 관람객. 화면보다 커서 드래그로 둘러본다 |

**모든 단계에 공통으로 있어야 하는 기능 지점** (그림 위치는 단계마다 달라도 됨)
- 카운터(NPC 판매), 시장 입구, 길드 입구, 교배실, 치어 육성, 진열 수조들
- 2·4단계 이미지에는 교배 장치·치어 수조가 안 보이고, 4단계에는 시장·길드 입구가 분명하지 않다. 에셋 제작 시 이 지점을 넣는다 (예: 4단계는 직원 전용 구역에 교배실·치어실, 기념품 가게 옆에 시장 입구).

**단계 장면 공통 규칙**
- 시점은 모든 단계에서 탑다운 3/4로 통일한다. 4단계 이미지는 원근감이 강해 쿼터뷰에 가까우므로 에셋 제작 시 1단계와 같은 각도로 맞춘다.
- 수조 속 물고기는 플레이어가 실제로 진열한 개체를 그린다. 빈 수조는 빈 물로 보인다.
- 관람객 수는 수족관 평가 점수와 연결할 수 있다 (제안).
- 1단계 안에서도 수조 자리 일부는 빈 받침대로 시작해 단계 진행도에 따라 채운다 (제안).

### 물고기 크기 기준 (360×640)
- 메인 수조: 몸길이 약 14–18px
- 진열 수조: 약 10–14px
- 치어: 약 5–7px
- 개체 상세 화면에서는 같은 레이어 합성 물고기를 크게(정수 배율) 보여 준다.
