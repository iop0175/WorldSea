# 월드씨 화면 구성 요소 목록 (v0.1)

지금까지 확정한 기획에서 화면에 나와야 하는 요소를 모두 모은 목록이다. 페이지 디자인의 기준으로 쓴다.
- **(확정)** 기획에서 정한 것. **(제안)** 기획에 직접 없지만 확정 기능을 쓰려면 필요한 것. 디자인 전에 확인.
- `[테이블]`은 그 화면이 읽고 쓰는 DB 테이블.
- 화면 형식: 9:16 세로. PC/웹은 가운데 세로 프레임. 2D 픽셀아트. 작은 한글은 캔버스가 아닌 UI 레이어에 그린다.

---

## 0. 공통 요소 (모든 화면)

- **상단 재화바** (확정): 골드, 프리미엄 재화, 스태미너(현재/최대 + 다음 회복까지 시간), 시간 티켓 `[players]`
- **하단 탭 5개** (확정): 샵 / 사육 / 원정 / 도감 / 상점
- **입질 알림 배너** (확정): 희귀어가 걸리면 화면 어디서든 뜸. 어종 실루엣, 등급, 남은 시간(30분), "지금 잡기" `[rare_bites]`
- **푸시 알림** (확정, 모바일만): 입질, 경매 낙찰/입찰 경쟁, 반복 수색 종료·정지
- **공통 팝업** (제안): 확인/취소, 보상 획득 연출(물고기·재화·아이템), 오류/네트워크 끊김, 레벨 업
- **광고 버튼 공통 규칙** (확정): 모바일에서만 동작. 웹/PC에서는 누르면 "광고는 모바일에서만 가능합니다"
- **잠금 표시** (확정): 레벨·구독·VIP 조건으로 잠긴 기능은 조건 문구와 함께 회색 처리

## 1. 시작 흐름

- **스플래시/로딩** (제안)
- **로그인** (확정): Supabase Auth 소셜 로그인. iOS는 Apple 로그인 버튼 필수 (제안: 게스트 시작 여부 결정 필요)
- **닉네임 설정** (확정, 20자) `[players.nickname]`
- **스토리 인트로** (확정): 작은 동네 브리딩샵을 물려받아 시작하는 식의 도입
- **점진적 해금 튜토리얼** (확정): 기능을 하나씩 열면서 안내. 진행 단계 저장 `[players.tutorialStep]`

## 2. 샵 탭 (허브)

### 2-1. 허브 메인 (확정)
- 샵 씬: 브리딩샵 → 공공 수족관으로 4단계 성장. 단계마다 배경·크기·수조 수가 바뀜 `[players.shopStage]`
- 진열 수조: 내가 진열한 물고기가 헤엄침 `[tanks(purpose=display), fish(status=display)]`
- 카운터: NPC 판매 입구
- 허브 안 입구: **시장**, **길드** (확정: 시장과 길드는 하단 탭이 아니라 샵 안에서 들어감)
- 샵 단계 업그레이드 버튼과 조건 (제안: 조건 수치 미정)
- 수족관 전시 평가 점수 (확정: 최종 콘텐츠) `[aquarium_ratings]`

### 2-2. 시장 (확정: 하이브리드)
- **NPC 판매**: 흔한 어종을 바로 판매. 어종별 현재 시세(희소할수록 비쌈, 야생 > 양식) `[market_prices, fish]`
- **경매 목록**: 희귀·모프·오리지널. 필터(어종/등급/모프/야생·양식), 정렬(마감 임박/가격) `[auctions]`
- **경매 상세**: 개체 정보(외형, 유전 모프, 건강, 야생/양식), 현재가, 입찰, 즉시 구매, 남은 시간, 입찰 기록 `[auctions, auction_bids, fish]`
- **경매 등록**: 개체 선택, 시작가/즉시 구매가/기간, 수수료 안내. 경매 불가 어종 표시 `[auctions]`
- **내 경매**: 판매 중/입찰 중/낙찰/유찰
- 신규 계정 제한 안내 (확정): 일정 레벨 전에는 경매 이용 불가

### 2-3. 길드 (확정)
- 길드 없음: 길드 찾기(검색/추천), 길드 만들기 `[guilds]`
- 길드 홈: 이름·소개, 멤버 목록과 역할(길드장/부길드장/멤버), 탈퇴·추방 `[guild_members]`
- **길드 퀘스트**: 위험종 복원 목표(어종, 목표 방류 수), 진행률, 내 기여도, 보상 `[guild_quests, guild_quest_contributions]`
- 서버 협동 복원 이벤트 현황 (확정) `[restoration_events, restoration_contributions]`

### 2-4. 수족관 전시 (확정: 최종 콘텐츠)
- 전시 배치/꾸미기, 다른 플레이어 수족관 방문·평가 `[aquarium_ratings]` (제안: 꾸미기 아이템은 코스메틱 소비처)

## 3. 사육 탭

### 3-1. 수조 목록 (확정)
- 수조 카드: 용도(교배/진열/보관), 개체 수, 환경 경고 `[tanks]`
- 수조 추가/확장 (제안: 비용 미정)

### 3-2. 수조 상세 (확정)
- 환경: 수온, 염도, 수질 게이지 + 적정 범위(어종별) `[tanks, species]`
- 자동화 설비: 여과기/히터/사료 자동급여기 레벨과 업그레이드 `[tanks.equipment]`
- 안에 있는 개체 목록

### 3-3. 개체 상세 (확정)
- 픽셀 외형(유전자 → 몸 팔레트/무늬/지느러미/크기 레이어 합성)
- 어종, 성별, 야생/양식, 크기, 건강, 성장도(성체 여부), 근친도, 모프 이름, 유전자형(우성/열성/공우성 표시), 부모 `[fish]`
- 행동: 수조 이동, 진열, 교배, 판매(NPC/경매), **방류**(복원 기여), 성장 아이템 사용

### 3-4. 교배 (확정)
- 부모 선택: 같은 어종의 성체 수컷·암컷. 교배 불가 어종(고대 전설급·오리지널) 표시 `[breedings, fish]`
- 예상 모프 확률 미리보기 (제안: 멘델 유전 계산을 보여주면 육종 재미가 커짐)
- 진행 타이머, **교배 촉진 아이템** 사용 (확정: breed_boost)
- 결과(부화): 새끼 개체, **세계 최초 모프 발견 → 명명권** 연출 (확정) `[morph_discoveries]`

### 3-5. 보관함 (확정)
- 수조 밖 보관 개체 목록 `[fish(status=holding)]`

## 4. 원정 탭

### 4-1. 원정 메인 (확정)
- **헌터 슬롯 1~4**: 헌터 외형, 상태(대기/수색 중/정지/완료), 잠긴 슬롯의 해금 조건(레벨 10 무렵, 월 구독, 높은 VIP) `[hunters]`
- 슬롯별 진행: 지역, 회차(n/N), 다음 결과까지 시간, 정지 사유(스태미너 부족/프리미엄 상한/장비 소진/직접 중지) `[expeditions]`
- 공유 스태미너 표시 (확정: 헌터들이 하나의 스태미너를 나눠 씀)
- 수령 대기 결과 일괄 수령

### 4-2. 지역 선택 (확정)
- 세계 지도: 4단계(민물 → 해역 → 고대), 레벨 잠금, 고대는 시간 티켓 필요(+일일 입장 제한) `[regions, daily_counters]`
- 지역 정보: 수색 1회 시간, 스태미너 소모, 출현 어종과 각 어종의 보전 상태(안정/취약/보호종/야생 멸종) `[regions, species, wild_populations]`

### 4-3. 수색 설정 (확정)
- 1회 / 반복 선택, 반복 횟수(최대 100, 구독 또는 높은 VIP 200)
- 스태미너 부족 시: 중단 / 자연 회복 기다리기 / 프리미엄 자동 구매(**상한 입력 필수**)
- 찌·미끼 사용 여부와 선택(사용 시 성공·실패 무관 시도마다 소모), 장비가 떨어지면 계속할지
- 이번 반복에만 적용할 미니게임 자동 설정 `[expeditions.options]`
- 예상 소모 스태미너·시간 요약 (제안)

### 4-4. 결과 수령 (확정)
- 물고기, 골드/프리미엄, 아이템(찌·미끼·성장·교배 촉진), 꽝 횟수 `[expeditions.result]`
- 특별 맵 발견 알림 → 4-6으로

### 4-5. 입질 미니게임 (확정)
- 판정 영역: 넓게 펼쳐진 영역, 가운데에 가까울수록 성공 확률 상승(포켓몬GO 채집 느낌, 반응 속도형 아님)
- 어종 실루엣/등급, 남은 시간(30분)
- 찌·미끼 선택(보정 표시), 자동으로 넘기기 버튼(확률 낮아짐 안내)
- 결과: 포획 성공 연출 / 놓침(물고기는 바다로) `[rare_bites]`

### 4-6. 특별 맵 (확정)
- 특별 지역 연출, 기회 5번 남은 횟수, 특별 개체(오리지널) `[special_encounters]`

### 4-7. 헌터 외형 (확정)
- 보유 외형 목록, 헌터별 외형 변경. 뽑기는 상점으로 연결 `[player_hunter_skins, hunters.skinId]`

## 5. 도감 탭 (확정)

- 어종 목록 120종: 단계/지역별 탭, 발견·미발견, 희귀도 색 `[species, dex_entries]`
- 어종 상세: 이름·학명, 희귀도, 서식 지역, 현재 보전 상태와 야생 개체수 비율, 발견한 모프 목록, 교배 가능 여부 `[species, wild_populations, dex_entries]`
- 모프 발견 기록: 세계 최초 발견자와 명명 이름 `[morph_discoveries]`
- 오리지널·특별 개체 별도 페이지
- "전설 목격" 기록 (확정: 숨은 보유량 연출)

---

## 6. 상점 탭 (확정)

- **장비**: 찌·미끼 골드 구매(3등급 rare까지) `[items, player_items]`
- **조합**: 같은 아이템 N개 → 한 등급 위 1개. 전설 전용 미끼는 조합 불가 표시
- **헌터 외형 뽑기**: 뽑기 버튼, 등급별 확률표 공개 링크 `[hunter_skins]`
- **프리미엄 재화 구매**: 모바일 인앱결제, 웹/PC Stripe `[purchases]`
- **월 구독**: 혜택(광고 제거, 매일 VIP 포인트, 헌터 슬롯 +1, 반복 200회) `[subscriptions]`
- **VIP 티어**: 아이언~챌린저 현재 등급, 포인트, 다음 등급까지, 등급별 편의 혜택 `[players.vipPoints, vipTier]`
- **스태미너·시간 티켓 구매**: 프리미엄 구매, 광고 보상, 일일 남은 횟수 `[daily_counters]`
- **광고 보상**: 골드/프리미엄/스태미너/시간 티켓, 일일 제한 (모바일만)

---

## 7. 기타 화면

- **인벤토리** (제안): 찌·미끼·성장·교배 촉진 아이템 수량, 등급별 정렬 `[player_items]`
- **출석 보상** (확정: 매일 출석 → VIP 포인트, 장비 보상) `[daily_counters]`
- **친구** (확정): 친구 목록, 요청 보내기/받기, 친구 수족관 방문(제안) `[friendships]`
- **프로필** (제안): 닉네임, 레벨, VIP 등급, 도감 달성률, 대표 물고기
- **설정**:
  - 미니게임 자동 진행 켜기/끄기 (확정) `[players.autoMinigame]`
  - 높은 등급 기준(rare/epic/legendary) (확정) `[players.highGradeThreshold]`
  - 높은 등급 입질 시 자동 진행 / 정지 후 알림 (확정) `[players.highGradeBiteMode]`
  - 푸시 알림 종류별 켜기/끄기 (제안) `[push_tokens]`
  - 계정, 로그아웃, 탈퇴 (제안)
- **확률 공개 페이지** (확정: 법적 원칙): 수색 결과 확률, 외형 뽑기 확률
- **이용약관·개인정보 처리방침** (제안: 출시 필수)

## 디자인 단계에서 정해야 할 것
1. 게스트 시작 허용 여부 (로그인 화면 구성이 달라짐)
2. 우편함 필요 여부 (길드 보상·이벤트 보상 전달 방식)
3. 하단 탭에 없는 인벤토리·친구·설정·출석을 어디서 여는지 (허브의 아이콘 / 상단바 메뉴 버튼 등)
4. 샵 단계 1~4별 허브 모습
5. 입질 미니게임 판정 영역의 모양 (원형 과녁 / 가로 막대 / 수면 위 원)
