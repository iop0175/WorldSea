# 메인 화면(샵 허브) UI 기준

기준 이미지: `docs/reference/main-ui-reference.jpg` (대장님 제공, 896×1200)
- 이 이미지를 메인 화면의 **기본 UI 기준**으로 삼는다. 화면 배치, 패널 모양, 색감, 아이콘 스타일은 이 이미지를 따른다.
- 단, 샵 장면은 **쿼터뷰 → 탑다운 뷰**로 바꾼다 (아래 4장).
- 이미지는 생성 도구로 만든 시안이라 그대로 에셋으로 쓰지 않는다 (오른쪽 아래 생성 도구 표시, 장면 속 한글 오타). 같은 스타일로 에셋을 새로 만든다.

## 1. 화면 영역 (위에서 아래로)

기준 이미지는 3:4 비율이다. 게임은 9:16 세로 프레임이므로 **상단바·헌터 띠·탭바는 가로폭 기준 고정 높이**, 남는 세로 공간은 전부 샵 장면이 쓴다.

| 영역 | 기준 이미지 위치(px) | 높이 / 가로폭 | 390폭 화면 환산 |
|---|---|---|---|
| ① 상단바 | y 0–92 | 10.3% | 약 40px (+상태표시줄 여백) |
| 구분선 | y 92–97 | 검정 굵은 선 | 2–3px |
| ② 샵 장면 | y 97–897 | 나머지 전부 | 9:16에서는 이미지보다 세로로 길어짐 |
| ③ 헌터 띠 | y 900–1072 | 19.2% | 약 75px |
| ④ 하단 탭바 | y 1088–1200 | 12.5% | 약 49px (+홈 표시줄 여백) |

## 2. 공통 스타일

**패널 규칙**
- 어두운 남청 바탕, 1px 검정 외곽 + 안쪽 1px 밝은 테두리, 모서리는 직각이거나 1~2px만 깎은 픽셀 모서리.
- 강조 패널(양옆 버튼 패널)은 청록 테두리가 은은하게 빛나는 느낌(외곽 글로우)을 준다.
- 숫자는 픽셀 글꼴, 한글은 굵고 둥근 고딕(이미지는 Do Hyeon 계열 느낌).

## 3. UI 요소 상세

### ① 상단바 (한 줄)
왼쪽부터:
1. **프로필 패널** (x 8–302): 헌터 얼굴(금색 테두리 정사각형) + 닉네임 + `LV.12`(금색 픽셀 글꼴) + 경험치 바(초록, 검정 트랙).
2. **재화 칸** (각각 어두운 패널, 아이콘 + 숫자):
   - 프리미엄 (x 318–500): 보라 보석 + `380` + `+` 충전 버튼
   - 스태미너 (x 515–690): 초록 번개 + `32/60`, 그 아래 작게 `+1 04:12`
   - 시간 티켓 (x 704–812): 청록 모래시계 + `3`
   - **수정: 골드 칸 추가.** 기준 이미지에 골드가 빠져 있다. 프로필 패널을 줄이고 골드(금화 + 숫자)를 프리미엄 앞에 넣는다.
3. **메뉴 버튼** (x 826–888): 햄버거 아이콘, 오른쪽 위 빨간 배지(새 소식 수: 우편 포함).

### ② 샵 장면 위에 얹는 UI
- **간판** (가운데 상단): 나무 바탕 + 금속 테두리 명판, "월드씨 브리딩샵".
  - 수정: 양옆 **용 장식 → 바다 모티프**(물결, 산호, 닻 중 하나).
- **샵 단계 바** (간판 바로 아래): 양끝 청록 보석 장식 + "1단계 동네 샵" + 금색 진행바 + `62%`.
- **왼쪽 패널** (화면 왼쪽 가장자리, 청록 글로우 테두리): 출석(달력, 배지) / 복원(분재).
- **오른쪽 패널**: 가방 / 친구.
- **장면 속 라벨**(진열 - 베타, 카운터 - 판매, 치어 육성, 연구 구역, 시장, 길드): 어두운 반투명 명판 + 흰 글자. **그림에 넣지 않고 UI 레이어 글자로 얹는다** (작은 해상도에서 한글이 깨지고, 이름이 바뀌어도 반영되게).
- 머리 위 아이콘 말풍선: 교배 완료(DNA), 손님 대기 등 상태 표시.

### ③ 헌터 띠
- 첫 줄: `헌터`(금색) + `1명 수색중 · 1명 완료`(보조색) ……… `모두 수령`(금색 버튼, 검정 테두리).
- 둘째 줄: 슬롯 카드 4개 (가로 4등분, 사이 간격 약 16px)
  - 수색 중: 어두운 청록 지도 무늬 바탕 + 지역명 + `37/100   02:41` + 하늘색 진행바
  - 완료: 금색 지도 무늬 바탕 + 지역명 + `완료 · 수령`
  - 잠김: 자물쇠 + 해금 조건. **수정: "대양 심해/특수 탐험" → "LV.10 해금", "구독 해금"** (슬롯은 지역이 아니라 조건으로 열림). 카드 모서리 용 장식도 바다 모티프로.

### ④ 하단 탭바
- 5칸 균등, 칸 사이 검정 세로선. 활성 탭은 금색 바탕 + 아래쪽 진한 금색 그림자.
- 아이콘(컬러 픽셀 아이콘, 약 40px) + 이름. 알림 배지는 아이콘 오른쪽 위.
  - 샵: 줄무늬 차양 가게 / 원정: 지도 / 도감: 왕관 책 / 상점: 파란 바구니
  - 사육: 기준 이미지는 **게**. 바다 생물이라 어울리긴 하지만 사육 대상은 물고기이므로 **물고기 또는 수조 아이콘으로 교체 권장**.
- 오른쪽 끝 ✦ 표시는 생성 도구 워터마크이므로 무시.

## 4. 샵 장면: 쿼터뷰 → 탑다운 뷰

### 시점
- **탑다운 3/4 시점**(포켓몬·스타듀밸리 같은 RPG식 탑다운): 위에서 내려다보되 물건의 **윗면과 앞면이 함께** 보인다.
- 완전한 수직 탑다운(정수리 시점)은 쓰지 않는다. 물고기 등만 보여서 몸통 색·무늬·지느러미(모프)가 안 보이기 때문. 3/4 시점이면 수조 앞 유리 너머로 **물고기 옆모습**이 보인다.
- 해상도는 그대로 180px 폭. 타일 15px 기준 가로 12칸.

### 배치도 (가로 12칸, 위가 벽)

```
행  0-2 : [액자] [진열-베타 벽수조]  [  간판  ]  [진열-구피 벽수조] [액자]   ← 뒷벽(벽면이 보임)
행    3 : 바닥 시작 ─────────────────────────────── [카운터-판매 + 점원]
행  4-8 : [왼쪽 패널]   [      메인 진열 수조 (6x4칸)      ] [연구 구역] [오른쪽 패널]
행 9-10 : 통로 (손님 NPC가 오가는 길)
행11-13 : [치어 육성 1] [치어 육성 2]            [시장 문] [길드 문]   ← 오른쪽 벽 문
행14-16 : 앞쪽 바닥, 입구 매트(초록), 손님 입장
```

- **뒷벽**: 나무 판자 벽, 액자, 간판. 진열 수조 2개는 벽에 붙은 선반 수조.
- **카운터**: 기준 이미지처럼 오른쪽 위. 점원이 서 있고 손님이 오면 말풍선.
- **메인 수조**: 가운데 크게. 바닥 장식(산호, 수초, 바위)이 보이는 큰 수조.
- **연구 구역 = 교배실**(제안): 유리 돔 장치 2개. 교배 중이면 안에 부모 물고기, 끝나면 DNA 말풍선.
- **치어 육성**: 왼쪽 아래 낮은 수조 2개, 작은 치어들.
- **시장·길드 문**: 오른쪽 아래, 문 앞 초록 매트. 문 위 명판은 UI 글자.
- **바닥**: 짙은 나무 또는 청록 타일. 손님과 직원 NPC가 통로를 따라 이동.
- **샵 단계 성장**: 1단계는 위 배치. 단계가 오르면 방이 넓어지고(가로로 스크롤 또는 축소 보기) 수조 칸이 늘어난다.

## 5. 탑다운 시안 이미지 생성용 프롬프트 (참고)

기준 이미지를 만든 도구에 아래처럼 요청하면 같은 스타일의 탑다운 버전을 받을 수 있다.

> 위 이미지와 같은 픽셀아트 스타일, 같은 UI(상단바, 헌터 띠, 하단 탭바)를 유지하고, 가운데 샵 장면만 **쿼터뷰(아이소메트릭)가 아닌 탑다운 3/4 시점**(포켓몬/스타듀밸리처럼 위에서 내려다보되 물건의 앞면이 보이는 시점)으로 다시 그려줘. 뒷벽에 액자, 간판, 벽 선반 수조 2개. 오른쪽 위에 카운터와 점원. 가운데 큰 메인 수조, 그 오른쪽에 유리 돔 교배 장치 2개. 왼쪽 아래 낮은 치어 수조 2개. 오른쪽 아래 벽에 나무 문 2개와 초록 매트. 수조 앞 유리로 물고기 옆모습이 보이게. 장면 안에는 글자를 넣지 마. 간판 양옆은 용 대신 물결/산호 장식. 상단바에 금화(골드) 칸 추가. 잠긴 헌터 슬롯 문구는 "LV.10 해금", "구독 해금". 사육 탭 아이콘은 물고기가 든 수조. 세로 9:16 비율.
